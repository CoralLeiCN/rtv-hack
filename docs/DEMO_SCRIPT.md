# Ranger Duck demo script

## Two-minute demo script

| Time | Show and say |
| --- | --- |
| 0:00–0:15 | “Ranger Duck turns wildlife video into a robot action with evidence you can inspect.” Introduce the scripted deer and simulated Microduck. |
| 0:15–0:40 | Choose Feeding and press Start. Show the live query and returned references. Explain that the search uses the existing VSS archive. |
| 0:40–1:05 | Select the reviewed feeding reference, play the real segment, and point out its source timestamps and reviewed behavior. |
| 1:05–1:30 | Press Copy this behavior. Show the ground-pick movement and controller-confirmed completion in the same scene. |
| 1:30–1:50 | Select an unreviewed reference and show that Copy stays disabled. Explain that retrieved captions alone do not authorize movement. |
| 1:50–2:00 | “We connect encounter, retrieval, inspectable evidence, and bounded action in one page.” Name the confirmed sponsor tools once the list is finalized. |

Before presenting, verify the reviewed feeding manifest still exists on the VM,
its reference appears unchanged in live results, and the complete sequence
works. If selected for the final, use the extra minute to explain the evidence
checks and architecture. Do not promise a walking or standing imitation until
its footage has been reviewed and the full flow verified.
